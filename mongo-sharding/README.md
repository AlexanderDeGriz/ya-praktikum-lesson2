Инструкция по разворациванию проекта
1. Перейдите в директорию ..\ya-praktikum-lesson2\mongo-sharding
2. Выполните запуск сервисов в докере командой:
docker compose up -d
3. Проверьте, что все сервисы поднялись командой
docker ps
(или же можно посмотреть в GUI части Docker Desktop, в Containers)
4. Если какой-то контейнет не поднялся, то необходимо перейти в логи контейнера и посмотреть ошибку
5. в браузере переходим на страницу http://localhost:8080/
Убеждаемся, что работает роутер и 2 шарда. Убеждаемся, что есть 1000 документов (создаются через mongo-init.sh)
6. Чтобы посмотреть количество документов в конкретном шарде - запускаем mongosh

docker exec -it shard1 mongosh --port 27018

или

docker exec -it shard2 mongosh --port 27019

переходим в бд somedb:

use somedb

и запрашиваем количество документов на шарде:
db.helloDoc.countDocuments()

  В сумме на двух шардах их должно быть 1000

7. После использования проекта гасим сервисы командой "docker compose down -v"
